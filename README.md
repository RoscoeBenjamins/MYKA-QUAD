# Myka Quad - Mini E# Myka Quad - Mini ERP

Live web version of the Myka Quad master workbook: invoices, receipts, purchases, expenses, customers, products, suppliers, double-entry accounting, trend analysis, forecasting, data-hygiene KPIs and an admin portal.

Frontend: index.html (GitHub Pages). Backend: Google Apps Script + Google Sheet in Google Drive (backend/Code.gs). The API URL lives in config.js.

No business data is stored in this repo.
